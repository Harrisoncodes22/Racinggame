# Velocity Cup

An arcade racing game for Roblox: 6 maps, 13 vehicles, items, drifting, waiting rooms for friends, a coin shop, game passes, a daily spin and fastest-lap leaderboards. Everything (hub, tracks, vehicles, UI) is built from code.

- `src/` — the game scripts, laid out for [Rojo](https://rojo.space) (`default.project.json`)
- `notes/` — an [Obsidian](https://obsidian.md) vault documenting the game. Open the `notes` folder as a vault and start at **Home**.

Quick start: install Rojo, run `rojo serve`, connect from the Rojo plugin in Studio, press Play. Details in `notes/Project Setup.md`.
